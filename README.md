# 婚礼邀请函 · 网页版

一个可以直接发链接的婚礼请柬页面。纯静态：`index.html` + `assets/` 图片，不依赖任何框架和后端。

## 本地预览

在 `web/` 目录下起一个静态服务器（不要直接双击 index.html，部分浏览器会拦截本地图片）：

```bash
cd web
python -m http.server 8811
```

然后手机/电脑打开 `http://127.0.0.1:8811/`。

## 部署成链接（三选一）

### 1. Vercel（最快，2 分钟）

1. 打开 https://vercel.com ，用 GitHub 或邮箱登录
2. 点 **Add New → Project → Deploy** 里的 **Upload**（或把 `web` 文件夹拖进去）
3. 部署完成后得到一个 `xxx.vercel.app` 链接，可以直接发微信

### 2. GitHub Pages（免费、稳定）

1. 新建一个仓库，把 `web/` 里的文件传到仓库根目录
2. 仓库 **Settings → Pages → Source** 选 `main` 分支 / `root`
3. 等 1 分钟，得到 `https://用户名.github.io/仓库名/`

### 3. 腾讯云 COS / 阿里云 OSS 静态托管

1. 新建存储桶，开启「静态网站」功能
2. 上传 `web/` 里的所有文件（保持目录结构）
3. 用桶的访问域名打开，或绑定自己的域名

> 域名需要备案才能在国内正常访问；Vercel 的默认域名一般可直接用，但在微信里打开可能提示「非官方页面」，点继续访问即可。

## 内容在哪里改

全部集中在 `index.html` 里，搜关键词就能改：

| 想改什么 | 搜这个 |
| --- | --- |
| 新人名字 | `潘宝澄` / `凌萌`（封面、邀请语落款、页脚都有） |
| 日期时间 | `2026-11-27`（出现在 3 处：封面、婚礼信息、倒计时脚本里的 `target`） |
| 地点地址 | `金水门江边酒楼` / `海南省海口市美兰区…` |
| 导航坐标 | `110.362738,20.053931`（高德链接里的经纬度，顺序是「经度,纬度」） |
| 流程 | 搜 `tl__item`，每条一个时间点 |
| 温馨提示 | 搜 `着装` / `停车` |
| 回执截止日 | 搜 `11 月 15 日` |
| 相册 | `photos` 由脚本自动生成 18 张，改名 `assets/photo-1.jpg … photo-18.jpg` 即可 |

## 回执是怎么收的

网页是纯静态的，没有服务器，所以回执的做法是：

1. 宾客填完表单点「提交回执」
2. 页面生成一段格式化文字（姓名/人数/用餐/住宿/留言）
3. 点「复制这段文字」，粘到微信发给新人

**想要自动收集**（宾客直接提交、你在后台看汇总），可以把表单接到：

- **腾讯问卷 / 金数据**：把 `<form>` 换成它们提供的嵌入代码
- **Formspree**：`<form action="https://formspree.io/f/你的ID" method="POST">`，邮箱收通知
- **飞书多维表格 / 金山文档表单**：同理

## 已知限制

- 微信内**自定义分享卡片**（标题、缩略图）需要公众号 + JS-SDK 签名，纯静态页做不到；目前分享时用的是页面 `<title>` 和首图。
- 页面用的字体是系统宋体（iOS 上是 Songti SC），安卓上会回落到默认字体，属正常现象。
